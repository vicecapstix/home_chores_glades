# Spec — #301 Seasonal chores part 2
**Behaviour:** chores with an active `offUntil` (`isOffNow`) render in a collapsed "💤 Off (N)" `<details class="off-chores">` after the normal sections (respecting the status/category filters), not in Overdue/Due/Upcoming/Done. Admin sees "Switch on now" per chore (`switchOnNow`): one `patchPaths` clearing `offUntil` (+ `lastDone = initialLastDone` for a not-done recurring chore, same as the automatic switch-back). Off chores are skipped in: filter pill counts, `todayProgress` (daily/family goal), `weekPlan` (planner), `chartRows` (print chart); notifications already skip them via `dueStatus`. A not-done off chore's check box is disabled and `toggleTask` refuses it with a toast.
**UI states:** admin: section + Switch on now. Member: section, no button, disabled box. Readonly TV: same section, no controls (span check, no buttons). Empty-state is not shown when only Off chores exist.
**Data shape:** none new (uses `offUntil`). **RBAC:** `switchOnNow` starts `if (READONLY || !isAdminFn()) return;`, is bound in main.js with `_isAdmin`, granular patch, try/catch + showToast. **Cost:** none.
**Concerns:** the check box of an off chore that is already done stays tickable so it can be unticked.
