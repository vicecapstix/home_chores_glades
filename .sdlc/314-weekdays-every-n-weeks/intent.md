# Intent — #314 Weekday chores every 2, 3 or 4 weeks

## Problem
Some chores repeat on a weekday but not every week (bins every other Tuesday, swimming kit every 2nd Friday). Fortnightly drifts from the day it's ticked; Weekdays is every week.

## Outcome / acceptance criteria
- [ ] For **Weekdays** chores, admin can pick "Every 1 / 2 / 3 / 4 weeks"; default 1 keeps today's behaviour
- [ ] An anchor week (Monday YYYY-MM-DD, set when saved) decides which weeks are on; off-weeks are never due and don't reset
- [ ] Due status, resets, This week planner and print chart honour it
- [ ] Templates and chore file keep it; READONLY/non-admin can't set it
- [ ] New optional fields `everyWeeks` (2–4) and `weekAnchor`, omitted when 1; CLAUDE.md updated

## Affected users
Admin; members and TV see the right due days.
