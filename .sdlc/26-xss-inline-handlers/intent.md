## Problem
`esc()` HTML-encodes `'` as `&#39;`, but the browser decodes entities before running inline `onclick` JS, so `onclick="window.memberSelect('O&#39;Brien')"` becomes broken JS. A member called O'Brien cannot log in (`src/auth.js:61`), and Toggle role / Set PIN buttons break (`src/main.js:177-178`); categories have the same pattern (`src/render.js:203`). A crafted name like `');alert(1);('` runs code on every device. Raw DB values are also injected unescaped: `t.id`, `st.id`, `tpl.id`, `t.freq`, `t.difficulty` (`src/render.js:257-316`, `src/ui.js:187-188`). Because the DB is world-writable this is stored XSS.
