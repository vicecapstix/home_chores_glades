# Intent — #105

## Problem
`saveTemplate` (`src/ui.js:193`) stores `tasks: []` when there are no chores. Firebase drops empty arrays, so after the next snapshot `tpl.tasks` is undefined. `renderTemplates` (`src/ui.js:185`) then throws on `tpl.tasks.length` before `openModal` runs, so the Templates button does nothing on every device; `applyTemplate` (`src/ui.js:215`) would throw on `tpl.tasks.forEach`. Templates also have no count/size cap.

- [ ] Saving a template with zero chores is refused with a toast

- [ ] `saveTemplate` writes only `templates/<id>` with `patchRoot` multi-path (not `writeState`)
