## Problem
`runOverdueCheck()` (`src/notifications.js:60`) calls `new Notification(...)`. On Android Chrome (and installed PWAs on Android) the `Notification` constructor throws `TypeError: Illegal constructor` — only `ServiceWorkerRegistration.showNotification()` works there. The error is uncaught, so overdue reminders never appear on family phones even after permission is granted, and the task is marked as notified anyway. The PWA already registers `sw.js` (#45), so the fix needs no new service.
