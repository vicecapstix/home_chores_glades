# Intent — #70 Holiday / pause mode: freeze chores and streaks while the family is away

Queue position: 3

## Problem
After a trip, every recurring chore shows as overdue, the TV fills with red, overdue notifications fire for the logged-in member's tasks, and streaks break. There's no way to say "we're away until Sunday".

## Outcome / acceptance criteria
- [ ] Admin sets a pause with an end date (`state/pause: { until: 'YYYY-MM-DD', by }`), or clears it
- [ ] While paused: no task is shown overdue, `checkTaskResets` doesn't reset, overdue notifications are suppressed, and a banner shows "Paused until …" (TV too)
- [ ] On resume, recurring tasks' `lastDone` is shifted forward by the paused duration (one multi-path update), so nothing is instantly overdue
- [ ] Streaks don't break for the paused days
- [ ] READONLY + admin guards; tests with fixed dates

## Affected users
Admin (sets it), members, readonly TV view.

## Constraints
- Cost guardrails: stays on GitHub Pages (`main` / root) and the existing Firebase RTDB on the free Spark plan. No Blaze-only features (Functions, Storage, Extensions), no new services, API keys, secrets or paid hosting. Keep history capped at 500 and reads small. Never write to or change rules on the live DB; tests use mocks only.
- One small field in `/state`; no scheduled backend — all done client-side on the next load after `until`.
- Deploy: run `npm run build:pages` and commit the root files so merging deploys (CI fails on drift).

## Open questions
None (default: pause is whole-house, not per member).
