# Intent - #102

Daily chores reset 24 h after completion, not at local midnight (can't tick today's chore)

Queue position: 3

## Problem
`checkTaskResets()` (`src/tasks.js:20`) resets a recurring task only when `now - lastDone >= freqDays * 86400000`, and `dueStatus`/`daysSince` in `src/utils.js` use the same elapsed-ms math. A daily chore ticked Monday 21:00 is still `done` on Tuesday at 20:00, so nobody can tick Tuesday's occurrence until 21:00. Completion times drift later every day. A daily chore with a 08:00 due time that was done Monday 09:00 is still 'done' at Tuesday 08:00, so it never shows overdue. Weekly/fortnightly/monthly chores drift the same way by time of day. Confirmed on main a56201d.

## Outcome / acceptance criteria
- [ ] Daily tasks reset at local midnight: a task done any time yesterday is not-done today (compare local calendar dates via `localDateStr`)
- [ ] Weekly/fortnightly/monthly reset when the number of local calendar days since `lastDone` ≥ `freqDays` (time of day ignored)
- [ ] `dueStatus` uses the same calendar-day rule so 'soon'/'overdue' agree with the reset
- [ ] Weekday (`freq: 'weekdays'`) tasks unchanged (they already use `prevScheduledStart`)
- [ ] Tests with fixed `now` values: done 21:00 → reset at 00:00 next day; done 00:05 → still done at 23:59 same day; weekly done Sun 22:00 → resets next Sun 00:00; DST-safe local dates
