## Problem
On every load the app shows nothing until Firebase answers. On a slow Wi-Fi TV or a phone with no signal, the family sees a blank screen even though the data was there a minute ago. The RTDB web SDK keeps no data on disk.

## Outcome / acceptance criteria
- [ ] After each snapshot, save a trimmed copy (members without `pinHash`, tasks, rewards, pause; history limited to the last 50) to `localStorage` under one key, guarded by try/catch and a ~200 KB size check
- [ ] On start, render from the cache immediately with a "Showing saved data — connecting…" banner (reuse the connection indicator from #46); writes stay disabled until the first live snapshot arrives
- [ ] Live snapshot replaces the cache view without wiping inline edits (#34 behaviour)
- [ ] Logging out of a member does not clear it (the TV needs it); "Clear saved data on this device" button in Settings
- [ ] Tests: cache written without `pinHash`, size cap, start-from-cache renders read-only, live snapshot takes over

Readonly TV view (main case), members and admin on phones/tablets.
